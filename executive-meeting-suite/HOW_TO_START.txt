     - Start the backend on port 5000
     - Start the frontend on port 3000
     - Open the app in your browser

MAC/LINUX USERS:
  Open two terminal windows:

  Terminal 1:
    cd backend
    npm run dev

  Terminal 2:
    cd frontend
    npm run dev

  Then open: http://localhost:3000

================================================================================
  TROUBLESHOOTING
================================================================================

Problem: "Connection refused" error
Solution:
  1. Check PostgreSQL is running
  2. Windows: Go to Services and start PostgreSQL Server
  3. Mac: Run "brew services start postgresql"
  4. Linux: Run "sudo service postgresql start"

Problem: "npm: command not found"
Solution: Install Node.js from https://nodejs.org

Problem: Port 3000 or 5000 already in use
Solution:
  1. Edit backend/.env and change PORT to 5001
  2. Edit frontend/vite.config.ts and change port to 3001

Problem: Database errors
Solution:
  1. Delete database: psql -U postgres -c "DROP DATABASE executive_meeting_suite;"
  2. Restart the backend - it will recreate the database automatically
