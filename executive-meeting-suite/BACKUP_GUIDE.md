# Executive Meeting Suite - Quick Backup Guide

## 🚀 Quick Start

### First Time Setup (DO THIS NOW!)
1. Open the app (double-click desktop shortcut)
2. Go to "💾 Backup & Restore"
3. Click "⬇️ Download Backup Now"
4. Save the file to your Documents folder or cloud storage
5. ✅ You now have a backup!

---

## 📥 How to Create a Backup (5 Seconds)

**When:** Anytime you want to save your data  
**How:**
1. Click "💾 Backup & Restore" in sidebar
2. Click "⬇️ Download Backup Now"
3. Save file to your preferred location
4. Done! ✅

**File Name Format:** `EMS_Backup_2026-08-26.json`

---

## 📤 How to Restore from Backup (10 Seconds)

**When:** After losing data or switching computers  
**How:**
1. Click "💾 Backup & Restore" in sidebar
2. Click "Choose File" button
3. Select your backup file (EMS_Backup_*.json)
4. Click "⬆️ Restore from File"
5. Done! ✅ All your data is back

---

## 💾 Where to Store Backups

### Option 1: Local Computer (NOT RECOMMENDED)
- Store on external USB drive
- Keep in a safe location
- **Risk:** If computer fails, backup is lost

### Option 2: Cloud Storage (RECOMMENDED)
- **OneDrive** - Microsoft cloud
- **Google Drive** - Google cloud
- **Dropbox** - Dropbox cloud
- **iCloud** - Apple cloud
- **Benefits:** Accessible from anywhere, automatic sync, safe from computer failure

### Option 3: Network Drive
- Company server
- Network attached storage (NAS)
- Network share drive
- **Benefits:** Centralized, backed up by IT team

### Best Practice
**Keep backups in 3 places:**
1. Your computer (for quick access)
2. Cloud storage (for accessibility)
3. External drive (for offline safety)

## 🆘 Recovery Scenarios

### Scenario 1: Accidental Data Deletion
**Problem:** I accidentally deleted an action item  
**Solution:**
1. Click "💾 Backup & Restore"
2. Click "Choose File" and select previous backup
3. Click "⬆️ Restore from File"
4. All data from that backup time is restored

### Scenario 2: Browser Cache Cleared
**Problem:** Someone cleared browser cache and data is gone  
**Solution:**
1. Go to "💾 Backup & Restore"
2. Upload your backup file
3. Click "Restore from File"
4. All data is recovered!

### Scenario 3: Computer Failure
**Problem:** Computer crashed and data is lost  
**Solution:**
1. Get backup file from cloud storage or external drive
2. Install app on new computer
3. Go to "💾 Backup & Restore"
4. Restore from backup file
5. All data is back!

### Scenario 4: Switching Computers
**Problem:** Moving to a new computer  
**Solution:**
1. Download backup from current computer
2. Store in cloud or external drive
3. Install app on new computer
4. Restore from backup file
5. You're ready to go!

## 📞 Quick Troubleshooting

**Q: Backup file won't download?**
A: Try different browser or check internet connection

**Q: Restore gives error?**
A: Make sure it's a valid EMS backup file (.json format)

**Q: Don't remember where I saved backup?**
A: Check Downloads folder, cloud storage, or Desktop

**Q: Backup file is very small?**
A: Normal if few items exist. Size grows with more data.

**Q: Can I open backup file in Excel?**
A: It's a JSON file. Best to open with text editor or restore through app.
